# Jabalpurverse

नर्मदे हर · Explore Jabalpur. Discover its stories. Experience it differently.

Near-zero-cost city platform for Jabalpur (PWA). See [Docs/JABALPURVERSE_BRD_Final.md](Docs/JABALPURVERSE_BRD_Final.md).

## Phase 0 (this repo)

- Astro + Preact bilingual shell
- Brand tokens (marble / river / diya)
- Content schema + CI validator
- Supabase RLS baseline
- Cloudflare Pages-ready

## Quick start

```bash
cp .env.example .env   # fill anon key
npm install
npm run validate
npm run dev
```

## Stack

Astro (hybrid) · Supabase · Cloudflare Pages · content in Git

Maintainer model: solo + community moderators. Recurring infra target: ₹0/month.
